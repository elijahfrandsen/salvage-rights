# Assets and software

Ship/wreck silhouettes, orbital motifs, favicon, social illustration, CSS theme and procedural audio were authored for this project. No copyrighted franchise art, external music, licensed image stock, or downloaded fonts are included. Fonts use system-installed Arial/Helvetica/monospace fallbacks.

Third-party package licenses remain in node_modules when installed; review them using the pinned package-lock.json. React, Express, Socket.IO, Zod, Vite, TypeScript, Vitest and Playwright are their respective upstream projects. No blanket license for those dependencies is asserted by this project.
